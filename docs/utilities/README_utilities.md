# Utilities and Tools

Run project tools from the repository root unless their help text says
otherwise.

- [World Validator CLI](WORLD_VALIDATOR_CLI.md) documents the maintained
  read-only world parser, lookup, reference, and validation commands.
- [Project scripts](../../scripts/README_scripts.md) maps deployment,
  operations, debugging, vessel, world, and other maintained script groups.
- `util/` contains standalone compatibility utilities; trace each utility's
  source and build target before use.

The previous catalog was removed because its command paths and tool inventory
were not source-verified against the current tree.
