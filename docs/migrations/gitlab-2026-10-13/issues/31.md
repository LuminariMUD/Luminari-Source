## Description

The postmaster's mail delivery (`src/comms/mail.c:380`) and the two forged-note paths in
`src/character/backgrounds.c` (lines 1119 and 1382) make a letter with `create_obj()` and then
set `item_number = 1`. The letter is not an object of the prototype at rnum 1, yet the game
treats it as one:

- `create_obj()` does not add it to `obj_index[1].number`, but `extract_obj()` takes it off that
  count. Each letter thrown away lowers the count of rnum 1's real objects, so zone resets that
  cap that prototype load more of it.
- It is not on the `obj_rnum_hash` chain of rnum 1. Before MR !26, removing it from the hash
  emptied that chain's bucket, and `get_obj_num()` stopped finding the prototype's objects. MR !26
  makes `remove_obj_from_rnum_hash()` leave alone a chain the object does not head.
- An OLC save of the prototype at rnum 1 takes the letters for its live objects, and a new
  prototype below it renumbers them with it.

Found while addressing the review of MR !26.
