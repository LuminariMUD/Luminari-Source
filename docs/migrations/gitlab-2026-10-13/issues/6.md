## Description

#4 changed player help in the development help DB and `lib/text/help/help.hlp` (commits
`a6d9eda29` and `a814d7cdc`), written through the help-sync delta writer (plan id
`work-item-4-artificer-help`). Production help was deliberately left unsynced when #4 merged.

Pending changes from #4:

- new artificer class entry (`ARTIFICER ARTIFICER-CLASS CLASS-ARTIFICER`);
- the device entry (`ARTIFICER-DEVICES DEVICE DEVICE-CREATE DEVICES TOTAL-DEVICE`) rewritten to the real `device` subcommands, charges, penalties and repair;
- `GNOMES RACE-GNOME RACE-GNOMES` lists Gnomish Tinkering and Brilliance and Blunder;
- the class roster entry no longer carries the two artificer keywords.

Help is published even when production does not yet run the code it documents.
