## Description

## Problem

The vessel steps S9 through S15 recorded these verification gaps and left them open. Each path
was checked once by hand or by a live gate, and none has a test that runs in `make test-all`.

1. **`shipbuy` and its trade-in when the ship-side write is refused.** Work item #14 asked for a
   database-backed test per command family for a refused ship-side write. The shipyard jobs,
   the summons, and the payouts have one (`unittests/CuTest/test_vessel_payment.c`,
   `test_vessel_loss.c`). `shipbuy` and the trade-in undo (`vessel_trade_in_undo()` in
   `src/vessels/vessels_edit.c`) do not: no unit-test world generates ship interiors, so only
   the loss gate (`scripts/vessels/test_vessel_loss_in_game.sh`) plays them.
   `unittests/CuTest/test_vessel_shipyard.c` covers only the charge that cannot be saved and
   the hull that cannot be delivered.
2. **A write and its undo both refused.** The hire and the summons that stand have unit tests.
   The trade-in whose records cannot be put right and the bought hull that stays in play
   (`src/vessels/vessels_edit.c`) have neither a test nor a gate. They were verified once by
   hand on 2026-10-04; the method is in `docs/testing/VESSEL_SYSTEM_TESTING.md` ("Vessel Loss
   Check").
3. **Smaller untested paths in `src/vessels/vessels_payment.c`:** a trade-in payout that cannot
   be saved, a refund whose own save fails, a lost reply on the prepared bounty statement, and a
   sale whose first write is refused and whose write-back also fails.
4. **No live gate accepts freight.** No gate script types `contractaccept`; the economy gate
   plants a freight settlement with SQL. The command is covered by
   `unittests/CuTest/test_vessel_rewards.c` only.
5. **The help import and the help delete** check the help-sync lock inside their transaction
   (`src/olc/hedit.c`), as the help save does, but only the save and the lock function have a
   test (`unittests/CuTest/test_database_transactions.c`).

## Completion criteria

- A unit-test fixture that can generate a ship interior, and with it tests for `shipbuy` and
  the trade-in: a refused write undone and refunded, and a refused undo that keeps the charge
  and tells the staff.
- Tests for the four paths in item 3.
- A `contractaccept` step in a live gate (the economy or the rules gate).
- Tests that drive the help import and the help delete with the lock lost.
- Or, for any item judged not worth a test, a line in `VESSEL_SYSTEM_TESTING.md` that says so.
