## Description

**Defect.** The player object loader logs a debug trace at every load of a sheath. `crash_restore_records()` logs `SHEATH1` for each loaded object that can be worn as a sheath, `load_sheath_contents()` logs `SHEATH2` to `SHEATH6`, and `objsave_parse_objects_db_sheath()` logs `SHEATH2a` to `SHEATH2g` and the text of its `SELECT` (`log("%s", buf)`), twice per sheath, once per slot. Every login of a character with a sheath adds a dozen lines to the system log that say nothing.

**Fix.** Remove the `log("SHEATH...")` lines and the query echo in `src/obj/objsave.c`. The `SYSERR` lines on a failed query stay.

**Aside.** `objs_from_sheath()` in the same file has no caller.

Seen while building phase 5 of [Object save fixes and arm pricing](https://gitlab.com/max757/Luminari-Source/-/blob/master/docs/ongoing-projects/object-save-fixes-and-arm-pricing.md) (#17); read from the code, not changed there.
