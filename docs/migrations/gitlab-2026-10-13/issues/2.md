## Description

Implement [`docs/ongoing-projects/DURIS_PLAYER_RACES_PLAN.md`](https://gitlab.com/max757/Luminari-Source/-/blob/master/docs/ongoing-projects/DURIS_PLAYER_RACES_PLAN.md). It holds each race's registry data, stats, feats and race point score, the code the race guide does not cover, and the order of work. Every design decision in it is settled.

- 12 creation races, IDs 152-163: Centaur, Githzerai, Firbolg, Githyanki, Kobold, Drider, Thri-Kreen, Minotaur, Kuo Toa, Orog, Harpy, Stormkin.
- 5 quest-only descend forms, IDs 55-59: Death Knight, Wight, Revenant, Shadow Beast, Phantom.

Steps from the plan, each ending green on `make -j$(nproc)`, `make test` and `make install`:

- [ ] 1. Shared mechanics: rename Leonine Frame to Tauric Frame, add the psionic resistance feat, let Cold Immunity work as a feat, make race-granted epic damage reduction work, share one transformation-only hard lock, and make the respec argument NULL-safe.
- [ ] 2. Creation races: registry, hit points, XP multipliers, family predicates, parser, terminal and web creation, tests.
- [ ] 3. Descend forms: registry, hard lock, quest race-reward conversion, qedit and the world validator, tests.
- [ ] 4. Help: one `RACE-<SLUG>` topic per race in one SQL component and `help.hlp`, plus PSIONIC RESISTANCE and EPIC-RACES.
- [ ] 5. Docs: move the settled content into `PLAYER_RACES_REFERENCE.md` and the other docs, then delete the plan.
- [ ] 6. Live check on port 4100.

Not in this work item:

- The descend forms' quests come later, one per form, modeled on the Vampire line (quest 34721, zone 347). Until they exist no character can become a form.
- Repairing missing racial feats on saved characters is planned separately in `docs/ongoing-projects/RACIAL_FEAT_LOGIN_REPAIR_PLAN.md`. If it lands first, the races plan's code items 2 and 3 can drop their race checks.
