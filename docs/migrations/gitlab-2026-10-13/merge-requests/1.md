## Description

Implements `docs/ongoing-projects/ARM_COUNT_PLAN.md`: one arm count replaces the three separate extra-limb mechanics. Equipment stays capped at four arms. The plan is retired, and `EXTRA_LIMB_MECHANICS.md` is now the record of the implemented system.

## What changes

- **`arm_count()`** (`src/core/utils.c`) replaces `has_four_arms()`. It starts at 2, adds a PC race's new signed `race_data.arm_adjust` (0 for every race, so no race changes; NPCs start at 2 because their `GET_RACE()` is a family ID), +2 for Four Arms and +1 per Extra Arms rank. `APPLY_FEAT` gear counts only from positions the intrinsic arms already open. Four Arms counts once across all sources. `hands_have()` is the count plus the vestigial arm, and is now exported.
- **`wear_slot_arms_needed()`** replaces `is_four_arm_wear_slot()`: 1/2/3/4-arm positions per the plan table. Counts from 0 up close or open positions for NPCs too; race anatomy still applies.
- **Wear command**: the pickers and the sleeve/glove/wrist overflow use only open positions, and full sets report correctly at 1 and 3 arms (no more "YOU SHOULD NEVER SEE THIS"). A launcher's second hand is charged, and two-hand items go to their pair's two-hand position. From three arms up, pair exclusivity is enforced in `equip_char()` too.
- **Lifecycle**: `limb_reconcile()` / `limb_defer_*()` / `limb_restore_validate()`. Closed positions empty in order, and the count is re-read after each displacement (cascading provider loss). A third arm splits a mixed first pair. Hand loss (6->5, a lost vestigial arm) trims held items first. Restore defers any closed position and validates the final hand budget. `save_char()` retries postponed positions once.
- **Combat**: Extra Arms no longer adds full-BAB swings. The second pair attacks from 3 arms, and the fourth hand needs 4. A `MONK_TYPE()` character passing `monk_gear_ok()` strikes unarmed with an empty third hand, using monk dice. An unarmed strike uses a hand for the third hand's spare-hand strength bonus.
- **Round plan**: `draw_attack_round_plan()` draws the extra flurry, Air Embodiment and Wilderness Warrior off-hand procs once per round. `perform_violence()` clears it at phase 1. Phases 2 and 3 replay it, along with phase 1's second-pair candidate list (`plan_second_pair()`) and numbering, so no attack changes phase within a round. A candidate the character no longer has (haste ended, weapon removed) keeps its ordinal and does not swing, and none is added mid-round.
- **Consumers**: one-hander bonus doubling needs an actual spare hand. A lone third-hand one-hander doubles only with a hand left after the primary's share (`second_pair_spare_hands()`), which the third hand's strength bonus also reads. `unsheath` draws each item only into an open, empty position with free hands. Anything else stays sheathed, and a later `unsheath` can draw it.
- **Docs and help**: the mechanics, save, race point and Duris docs, both feats' text, and EXTRA-ARMS / FOUR-ARMS in `help.hlp`, the SQL seed and the dev help DB (all three verified identical).

## Intentional behavior changes

- Extra Arms means one arm per rank instead of one swing per rank (no race grants it; check saved characters and staff items before deploying).
- Monks with 3+ arms get an unarmed third hand.
- A bow in `WIELD_1` beside a held item is now refused, because it needs two hands.
- One-armed and over-budget first-pair one-handers no longer double item bonuses.
- The extra flurry, Air Embodiment and Wilderness Warrior off-hand procs roll once per round, as their perk docs say, instead of once per phase call. The Air Embodiment message appears once per round.
- A three-armed unarmed third hand keeps plain STR (no +2): the primary's strike and support hand and its own strike use all three hands.
- A third-hand one-hander beside a first-pair one-hander doubles its item bonuses only when a hand is left after the primary's support hand (four hands, for example four arms).
- `unsheath` no longer refuses when a first-pair hand is occupied. It draws what fits and leaves the rest sheathed for a later `unsheath`.
