## Description

- Invoking the help-sync skill now means one complete `sync --authorize-production` run to
  verified publication on both endpoints. It no longer downgrades to audit/plan, asks before
  publishing, or holds help back because production does not yet run the code it documents
  (skill, agent metadata, AGENTS.md).
- The representative lookup in `verify_endpoint()` matched stored keywords with `BINARY`, but
  catalog keywords are normalized to upper case while most stored rows keep their authored case.
  Every sync stopped once the sampled middle entry (`mastermind`, stored as `Mastermind`) was
  mixed case. It now matches case-insensitively, like the game's lookup.

Validation: help-sync suite with `LUMINARI_HELP_SYNC_INTEGRATION=1` (38 tests; the new
`test_verify_accepts_stored_keywords_in_authored_case` fails without the fix); local
`quality-format-check` and `hygiene-hygiene` jobs.
