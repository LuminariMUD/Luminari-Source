## Resolution (2026-09-18)

- Twelve new entries were authored in the development database and published to
  production with the help-sync engine: SPELL-SLOTS, ABLE-LEARNER, SELF-SUFFICIENT,
  JOLT, RAY-OF-FROST, SPELLSTRIKE, AURA-OF-DESECRATION, MSDP, ENCUMBRANCE,
  CRAFTING-STATIONS, CLASS-SHIFTER, and the staff entry MROLWALKTO.
- Forty-five alias keywords were added to existing entries, covering every row in the
  alias table above except `newplayerchat` (the NEWBIE entry is a welcome page, not a
  channel), `divine-bloodline` (no such bloodline exists), `air elemental`,
  `feat eidolon`, and the two free-text phrases.
- Typos were not added. The help command already answered a miss with phonetic and
  substring suggestions; the lookup now also ranks keywords by edit distance ahead of
  those, so `logds` suggests `logs` before `LIQUIDS` and transposed letters resolve.
  See `help_keyword_edit_distance()` in `src/core/help.c` and
  `unittests/CuTest/test_help_suggestions.c`.
- Still open, pending a design decision: `dominion`, `reshape`, `point-buy`,
  `companion-orders` beyond the ORDER alias, `ranger-abilities`, and per-weapon help
  pages. `spells paladin` currently aliases to the PALADIN class entry.
- Found while verifying: the database lookup in `search_help()` and both suggestion
  queries read only `help_keywords`. 415 entries carry 1,449 tokens in
  `help_entries.alternate_keywords` that appear on their keyword line in `help.hlp` but
  have no `help_keywords` row, so `help logs` (an alias of SYSLOG) and `help ammo` (an
  alias of BLAST) fail in game even though the file lists them. Some of that alias data
  is misfiled (GOSSIP and GRATS sit on the AUCTION entry), so promoting every alias to a
  lookup keyword needs a review pass first. Tracked as issue #204. DONE in code: the
  three queries now match alias tokens through a shared SQL prefix, with a real keyword
  outranking an alias when both match (`help gossip` lists the CHAT and AUCTALK keyword
  owners before the AUCTION alias). The misfiled aliases remain a help data cleanup.
