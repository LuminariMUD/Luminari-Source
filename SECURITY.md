# Security Policy

## Supported Versions

The repository does not currently publish a supported-version matrix. Project
owners must define which release lines receive security fixes before a version
can be represented as supported.

## Reporting a Vulnerability

Do not include exploit details, credentials, personal data, or production data
in a public issue. This repository does not yet publish a private security
contact or checked-in private-reporting procedure. Project owners should
configure GitHub private vulnerability reporting or publish an equivalent
private contact and response policy.

Until that organizational decision is recorded, this file cannot promise an
acknowledgment time, remediation SLA, disclosure window, or supported release.
